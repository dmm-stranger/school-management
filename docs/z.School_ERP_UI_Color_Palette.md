## Design Style

- Primary Font: Poppins (Headings), Inter (Body)

- Border Radius: 12px for cards, 8px for buttons and inputs, 9999px for pills/badges

- Shadow: Soft, subtle shadows (shadow-sm, shadow-md)

- Spacing: 8px spacing system (8, 16, 24, 32, 48, 64)
